# Public Assets Directory

Place your static assets here (images, fonts, etc.).

## Logo File

Please save your brand logo as:
- **File name:** `logo.png` (or `logo.svg`, `logo.jpg`)
- **Location:** `/public/logo.png`
- **Recommended size:** 40x40px to 80x80px for header use

The logo will automatically appear in the header next to the hamburger menu.

If the logo file is not found, the system will fall back to the text "TI" logo.
